# CO3011 deliverable checklist

## Milestone 1 — Initiation and Definition
- [ ] 1.1 Client consultation and real Client Interaction Log
- [ ] 1.2 Background, business context, assumptions and constraints
- [ ] 1.3 Benefits, disbenefits, costs, go/no-go evaluation
- [ ] 1.4 Scope, exclusions, objectives, measurable effectiveness
- [ ] 1.5 Project authority, sponsor/client, PM, escalation
- [ ] 1.6 Stakeholder interests/influence/engagement
- [ ] 1.7 Infrastructure, roles, standards, communication
- [ ] 1.8 Project characteristics, high-level risks, lifecycle

## Milestone 2 — Baseline
- [ ] 2.1 Product Breakdown Structure (PBS)
- [ ] 2.2 At least five Product Descriptions (PDs)
- [ ] 2.3 Product Flow Diagram (PFD)
- [ ] 2.4 Activities and logical activity network
- [ ] 2.5 Checkpoints including failure handling
- [ ] 2.6 Bottom-up effort estimates (person-hours vs elapsed time)
- [ ] 2.7 Activity decomposition/bundling
- [ ] 2.8 Quantified activity risks, owners and responses
- [ ] 2.9 Risk-response activities incorporated into plan
- [ ] 2.10 Resource-constrained schedule and allocation
- [ ] 2.11 Cost/schedule baseline, Gantt, critical path if applicable
- [ ] 2.12 Quality review and Project Baseline V1.0

## Milestone 3 — Execution
- [ ] 3.1 Implement client-approved core workflows
- [ ] 3.2 Weekly logs with actual/planned effort
- [ ] 3.3 Planned versus actual dates and effort
- [ ] 3.4 Live risk/issue log
- [ ] 3.5 Quality tests and verification evidence
- [ ] 3.6 Lecturer-issued change/event impact analysis
- [ ] 3.7 Approved Baseline V2.0 if necessary; preserve V1.0
- [ ] 3.8 Lower-level plans as new information emerges

## Final
- [ ] 4.1 Demonstration and completed/deferred/removed scope
- [ ] 4.2 Actual versus baseline performance
- [ ] 4.3 Achievement of original objectives and measures
- [ ] 4.4 Acceptance/handover and closure
- [ ] 4.5 Lessons learned
- [ ] 4.6 Individual contribution/reflection and viva
- [ ] Final project-management PDF, code repository and run instructions
- [ ] Objective–Product–Activity–Resource–Risk–Test–Checkpoint traceability
- [ ] Declaration of AI tools used and tasks supported

Milestone and final deadlines: check LMS; the provided PDF states TBD for final.

## Evidence Center – V9 implementation note

Staff users can record real evidence and export it through the new **Hồ sơ CO3011** screen. The app checks presence of major deliverable categories and some specific counts (e.g., at least 5 Product Descriptions), but it does **not** complete these tasks automatically. Keep each checkbox unchecked until actual data, client responses, approved plans and test outcomes have been verified by the team. Consult `docs/CO3011_EVIDENCE_EXPORT.md` for evidence mapping and data limitations.
